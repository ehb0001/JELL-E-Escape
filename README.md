# JELL-E: Escape the Lab

바닐라 JS + Canvas 2D로 만든 모바일 퍼즐 게임. 젤리 캐릭터를 스와이프로 밀어서 그리드를 이동하며, 특정 벽에 부딪히면 파워(상태)를 얻어 다른 장애물을 넘고 포탈에 도달하면 스테이지 클리어. 현재 2D 그리드에 층(Z축) 개념을 얹어 3D 퍼즐로 확장하는 작업 진행 중.

- 실행: `blob-escape/index.html`을 정적 서버로 서빙 (레벨 데이터를 fetch로 로드하므로 `file://` 직접 열기는 불가 — `python3 -m http.server` 등 사용)
- 소스: `blob-escape/js/` (game.js, level_new.js, player.js, input.js, effects.js, constants.js)
- 레벨 데이터: `blob-escape/levels/level_*.json` + `manifest.json`

## 조작

- 스와이프 / 방향키·WASD — 이동
- **Tab** (짧게) — 시점 전환 (X-Y ↔ Z-Y 뷰), 주인공 위치 기준으로 새 슬라이스 세팅
- **Tab** (길게, 280ms+) — 누르고 있는 동안 보드 위 마우스가 가리키는 칸이 하이라이트됨. 뗄 때 그 칸의 좌표가 새 뷰의 고정 슬라이스가 됨(주인공 위치 대신 직접 지정)
- **Q / E** — 현재 시점의 슬라이스(층 또는 열) 이동. 경계에서는 아무 효과 없음

## 아이템

| 아이템 | 부여 상태 | 트리거 조건 | 결과 동작 | 턴 소비 |
|---|---|---|---|---|
| 🧲 자석 | MAGNET | 이동 중 옆 칸에 금속벽이 스치면 | 그 자리에서 즉시 정지 + 충돌 이펙트, 상태 NORMAL로 리셋 | 정상 이동의 일부 |
| ❄️ 얼음 | ICE | 이동 중 벽에 정면 충돌하면 | 조용히 멈춘 뒤 입력 대기 → 좌/우 한 칸 꺾임(또는 충돌), 완료 시 상태 NORMAL로 리셋 | 꺾기 자체는 턴 미소비 |
| ⚡ 전기 | ELECTRIC | 전기문에 도달하면 | 문을 통과, 상태 NORMAL로 리셋 | 정상 이동의 일부 |

지형 오브젝트로 고무벽(`R`)도 있음 — 상태 무관하게 부딪히면 뒤로 최대 2칸 튕겨나감.

아이템은 이동 경로 중 밟는 즉시 시각 효과(색 전환/파티클)가 나타나지만, 게임플레이 효과(자석 정지, 얼음 꺾기, 전기문 통과)는 **다음 턴부터** 적용됨.

## 3D 확장

레벨 맵은 `map[z][y][x]` 구조 — 층(Z) 여러 개를 쌓을 수 있음. 현재 두 가지 시점을 지원:

- **X-Y 뷰(기본)**: 층(Z) 고정, 기존 게임 화면. 상하좌우가 각각 Y/X 이동
- **Z-Y 뷰**: 열(X) 고정, 시계방향 90도 회전해서 표시 (가로=Z, 세로=Y). 상하는 Y, 좌우는 Z 이동

Tab으로 전환 시 그 순간의 주인공 위치를 기준으로 슬라이스가 세팅되고, 이후 주인공이 움직여도 시점은 따라가지 않음(Q/E로 독립적으로 자유 이동). 층(Z) 이동은 Z-Y 뷰로 전환한 뒤 좌/우로 슬라이드해야 가능 — X-Y 뷰에서는 Z가 바뀌지 않음. 자세한 설계는 `CHANGELOG.md` 참고.

아이템 효과(자석 정지, 얼음 꺾기)도 축에 상관없이 3D 전체에서 동일하게 동작 — 예: Z축으로 슬라이드 중에도 옆(Y축)에 금속벽이 있으면 자석이 멈추고, Y축 슬라이드가 막히면 얼음이 Z축으로 한 칸 꺾일 수 있음.

바닥/아이템 칸에서 E로 가는 다음 슬라이스의 같은 자리도 지나다닐 수 있는 곳이면 위아래로 이어지는 샤프트로 보고 배경이 비쳐 보임(벽은 항상 그대로 렌더링).

사이드바에서 X-Y/Z-Y 뷰 각각 좌우·상하 반전 여부와 효과음을 설정할 수 있음(저장됨). 화면이 반전돼도 스와이프 방향과 실제 이동 방향은 항상 일치.
